# lixard-wow.github.io

User guides for Lixard's World of Warcraft addons, published at https://lixard-wow.github.io.

Plain HTML and CSS, served by GitHub Pages from the `main` branch. No build step.

| Page | Folder |
|---|---|
| Home | `index.html` |
| Profession Knowledge Treasures | `profession-knowledge-treasures/` |
| CharacterStats | `characterstats/` |
| HealerMana | `healermana/` |
| Mark of the Tank | `mark-of-the-tank/` |
| Auto Expansion Filter | `auto-expansion-filter/` |

Shared styles live in `assets/site.css`. When an addon ships a new version, update its "What's new" section and any changed commands or settings.
