Auto Expansion Filter

Turns on "Current Expansion Only" for you every time you open the Auction House or browse Crafting Orders. No setup needed.

Features

Auction House

  • Every time the search bar appears, Current Expansion Only is turned on in its Filter menu.

Crafting Orders

  • When you browse customer orders, the same filter is turned on there too.

Your choice

  • Each window has its own on/off switch.
  • The filter is set again a few times as the window opens, because the game doesn't always accept the change on the first try.
  • No other window or filter is changed. Settings apply to every character on your account.

Installing

The easiest way is the CurseForge app: search for Auto Expansion Filter and press Install.

To install by hand:

  1. Download the zip from CurseForge, or from GitHub (Code > Download ZIP).
  2. Copy the AutoExpansionFilter folder into World of Warcraft\_retail_\Interface\AddOns. If you downloaded from GitHub, rename the folder to AutoExpansionFilter if it has a different name.
  3. Restart the game the first time, so it finds the new addon.

Getting started

  1. Install the addon and log in.
  2. Open the Auction House or browse Crafting Orders. Current Expansion Only is already on.

That's it. Both filters are on from the start.

Settings

Type /aef to open the settings window. It shows the addon version under the title. Drag it to move it, and press Close or Escape to close it.

Auto-filter: Auction House
Turns Current Expansion Only on each time the Auction House opens. When unticked, the addon turns the filter off there instead. On by default.
Auto-filter: Crafting Orders
Does the same for the Crafting Orders browser. On by default.

Commands

Type thisTo do this
/aefOpen the settings window.
/aef onTurn on both filters.
/aef offTurn off both filters.
/aef helpList the commands in chat.

/autofilter and /expfilter work the same as /aef. You can also type /aef config, /aef enable or /aef disable.

Tips and FAQ

I unticked the filter in the Auction House, but it came back.

The addon sets the filter every time the window opens, so a change you make by hand lasts until the next time you open it. To keep it off, untick that window in /aef.

What happens when I turn a switch off?

The addon then turns Current Expansion Only off each time that window opens, instead of on.

It says "Config not loaded yet".

You typed the command before the game finished loading. Wait a moment and try again.

Do I need to set it up on each character?

No. Your settings are shared by every character on your account.
