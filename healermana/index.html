HealerMana

HealerMana shows the mana of every healer in your group or raid in one small display, so a glance tells you who is about to run dry.

Features

The display

  • Every healer's mana as a percentage, updated live, shown as icons or bars.
  • A horizontal row, a vertical list or a grid.
  • Class colors and spec icons for each healer.
  • Healers who are out of range fade out.

Status at a glance

  • Dead and Offline replace the percentage. A healer who is both shows Offline.
  • In icon style, a healer's icon changes to their food and drink icon while they eat or drink.
  • A Druid healer in Cat, Bear or Moonkin Form shows that form's spec icon (icon style) or a [Cat], [Bear] or [Moonkin] tag (bar style). Mana is hidden in Cat and Bear Form, since neither uses it.

Your setup

  • Choose where it shows: open world, dungeons, raids, scenarios, battlegrounds and arenas, each on or off.
  • Sort healers alphabetically or by class.
  • Move it, resize it and lock it in place. Your settings are saved.
  • A settings window with five themes to pick from.

Works with every healer spec: Holy and Discipline Priest, Restoration Druid, Holy Paladin, Restoration Shaman, Mistweaver Monk and Preservation Evoker.

Installing

The easiest way is the CurseForge app: search for HealerMana and click Install.

To install by hand:

  1. Download the zip from CurseForge, or from GitHub at github.com/lixard-wow/HealerMana (Code > Download ZIP).
  2. Copy the HealerMana folder into World of Warcraft\_retail_\Interface\AddOns.
  3. Restart the game the first time, so it picks up the new addon.

Getting started

  1. Join a group that has a healer, including yourself if you play one. The display appears just right of the middle of your screen.
  2. Type /hm or click the minimap button to open settings. Pick icons or bars, then adjust the size, spacing and sorting.
  3. Drag the display where you want it, then turn on Lock frame (click-through) so you don't move it by accident.

Want to set it up without a group? Press Start Preview at the bottom of the settings window to show fake healers. The number next to it sets how many (1 to 20). Press Stop Preview to go back to your real group.

Settings

Open settings with /hm or the minimap button. The bottom of the window has Reset Position, Start Preview and Close. Escape also closes the window. The gear in the title bar switches the window's theme.

General

Display Style
Icons or Bars. Icons by default.
Theme
The look of the settings window: Workbench, Artisan Ledger, Horde, Alliance or Slate.
Dim when out of range
Fades healers who are too far away. On by default. Out of Range Opacity sets how faded they look.
Hide own bar
Leaves yourself out of the display.
Lock frame (click-through)
Locks the display in place and lets clicks pass through it.
Show minimap icon
Shows or hides the minimap button.

Layout

Layout Mode
Horizontal, Vertical or Grid. Vertical by default.
Icon Size and spacing
How big the icons are and how far apart the healers sit.
Grid Columns
How many healers per row in Grid mode.
Bar Width, Bar Height, Bar Texture
Used with the Bars style.

Fill Color

Fill Color Mode
Class Color or one Custom Color for the bar fill and icon tint.
Bar Opacity, Icon Tint Opacity
How solid the bar fill is, and how strongly icons are tinted.

Background & Border

This tab is called Background with bars and Border with icons.

Background Color
The color behind each bar.
Class color border
Gives each icon a border in the healer's class color. Turn it off to pick a Border Color.

Text

Show player name
Shows each healer's name. Long Name Handling picks Shrink to Fit or Truncate.
Class color name, Class color percent
Colors the text by class. Turn them off to pick your own color.
Show % symbol
Adds a % after the number.
Font, Override font size
Change the font, and set the name and percent sizes yourself.

Sort & Visibility

Sort By
Alphabetical or Healer Class.
Show when Solo
Shows the display even when you're not in a group. Off by default.
Show in Open World, Dungeons, Raids, Scenarios, Battlegrounds, Arenas
Where the display appears. All on by default.

The Help tab explains each part of the window in game.

Commands

Type thisTo do this
/hmOpen settings.
/hm lockLock or unlock the display.
/hm alphaSort healers alphabetically.
/hm classSort healers by class.
/hm layoutSwitch between horizontal and vertical.
/hm resetPut the display back in its default position.
/hm raid 5Show fake healers to preview a layout, up to 20.
/hm raid offGo back to your real group.
/hm helpList the commands in chat.

/healermana works the same as /hm.

Tips and FAQ

The display isn't showing. Why?

It only shows when you're grouped with a healer, in content turned on under Sort & Visibility. Turn on Show when Solo to see it on your own, or use Start Preview.

Why doesn't the food and drink icon show in Mythic+?

Blizzard blocks addons from seeing this for the whole Mythic+ run, not just during pulls. There's no way around it. It works everywhere else.

Why is a healer's icon generic for a moment?

HealerMana looks up each healer's spec in the background. Until it knows, it shows a class icon. The lookup pauses while you have someone's Inspect window open.

Why is the Moonkin marker slow to change?

Moonkin Form only updates outside combat. Cat and Bear Form update during combat too.

I don't see the Font or Bar Texture options.

Those lists come from a shared font and texture library that many addons include. If none of your addons have it, HealerMana uses its default font and texture.

I can't drag the display.

It's locked. Turn off Lock frame (click-through) under General, or type /hm lock.
