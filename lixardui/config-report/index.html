Settings simplification: final report

Branch config-simplify, builds 0.0.855 to 0.0.865 (commits c13ac854 to e0487f9a). main was not touched. Nothing here is tested in game yet. No SavedVariables key was renamed or removed, no default changed, no slash command changed.

What changed, in one list

  1. Sidebar navigation. The chapter buttons and the index tray are gone. A left sidebar lists every module once, under Start here, Frames, On screen, Social, Items, Helpers and Setup. A module's sub-pages are tabs under its title.
  2. Up front plus More options. Every tab shows its common rows (4 to 6, hand-picked per module), then a folded MORE OPTIONS card with small group headings. Tabs with 6 or fewer rows show everything.
  3. Look rows live with their module. Corners, borders, opacity, fonts and textures that a module adds to General now sit on that module's Look tab.
  4. Change markers and Reset page. On every page, a changed switch, slider or dropdown gets an amber diamond; clicking it resets that row. Reset page (n) resets the open tab after a second click.
  5. Shared look (Chat pilot). Chat font and outline can follow the shared setting (Use shared / Override). Only Chat uses this so far.
  6. Search. Press / to search; results show the working control plus where it lives.
  7. Move mode popover. The gear popover shows position, Reset position, All settings and only size and arrangement rows. Look and behaviour rows stay on the settings page.
  8. Segmented control for 2 to 3 choice settings (Chat outline, active tab style).
  9. Timing. Opening the settings window logs any step over 30 ms to /lui perf slow.

Skipped or not built

  • Per-frame scale and anchor in the popover. Most frames have no scale or anchor setting; adding them is new functionality, so the popover only shows the size rows a frame already has.
  • Frame chips for Unit frames and Party and raid: the tabs already pick the frame. Instead the tab bar tightens its padding to fit one row.
  • Shared look beyond Chat. Font, size, outline, bar texture and accent inherit through the existing "Same as General" values; only Chat got the Use shared / Override row. Other modules would need the same per-row work.
  • One-line descriptions: existing rows keep their text; no new descriptions were written.
  • Position stored once: the six window position stores were left as they are (a merge would be a migration; you chose not to).
  • Audit bugs not fixed (need your OK): unreachable role-icon switches, Minimap gear label mismatch, chat resize grip ignoring the lock, Hide() calls without combat guards.

Uncertain

  • Default probe. Markers on pages without a path find the default by running the row's getter against a read-only copy of the default profile. A getter that computes from something else (another addon, per-character data, a cached table) may show no marker; a wrong default would show a diamond on a row you never touched. Color pickers, buttons, lists, per-character and account-wide settings (Friends, Vendor sell rules, Addon manager) are never marked or reset.
  • Reset page calls each row's own setter; rows that need /rl will ask for it.
  • Over-limit tabs: Minimap › Map buttons (9), Info bars › Data text bars (8), Unit frames › Pet (7).
  • Placement labels in the popover are matched by English label text; a translated client would show the full list (no loss, just not trimmed) until labels get keys.

Check against current Midnight behaviour

  • SetPropagateKeyboardInput (used for the / search key) is protected in combat; the code skips it in combat and retries after. Confirm no ADDON_ACTION_BLOCKED when pressing / in combat with the window open.
  • The settings window still builds a page's rows on first open; confirm no taint or blocked-action errors when opening it in combat (it touches no secure frames).
  • Reset page on a page that enables or disables Blizzard frame replacements (unit frames, action bars, bags) in combat: those setters already queue through ns.Combat:Run; confirm nothing errors.
