Trailmark: waypoint

How Trailmark shows where to go. Pick Trailmark's own marker, Blizzard's (which WaypointUI and the LixardUI waypoint draw on), or TomTom. Trailmark's marker follows your look: a brass compass, a red wax seal or a glowing rune stone. These pictures use the real marker art from the addon. Built in 0.19.0, not tested in game yet.

Which marker is used

Settings > Finding the way > Waypoint. The line next to it says which one is in use right now.

Automatic

Picks for you, so two markers never fight over the same spot.

WaypointUI or LixardUI waypoint installed: Blizzard's marker (they draw on it). Else TomTom if installed. Else Trailmark's own.

Trailmark

The themed marker above, with the step name, yards and an edge arrow. Blizzard's marker is hidden while it shows.

Best when you use no other waypoint addon.

Blizzard

The game's own marker. WaypointUI and the LixardUI waypoint restyle this one, so pick it when you use them.

Trailmark still sets the spot for every step.

TomTom

Each step becomes a TomTom waypoint with TomTom's arrow; the old one is removed.

Needs TomTom. Steps that only point at a quest area have no exact spot, so TomTom gets nothing for those.
